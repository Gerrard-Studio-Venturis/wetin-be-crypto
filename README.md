# Wetin Be Crypto — Research and Design

This repository holds the planning work for a WordPress crypto education application serving a wider African audience with a West African focus.

The agreed direction is a guided foundation with practical missions, free public lessons and articles, optional accounts for saved learning and article bookmarks, and clear English with occasional varied Nigerian Pidgin.

The engagement covers research, planning, noncode design, and a development-team handoff. A completed or approved plan does not trigger application coding by the planning assistant.

The detailed planning package and concise reviewer brief will be proposed on the `docs/research-design-plan` branch for review. Documentation updates will be published at meaningful checkpoints during active work.
